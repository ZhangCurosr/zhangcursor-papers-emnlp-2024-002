# 论文速读：Word-Alignment-as-Preference-for-Machine-Translation

## 一句话总结
本文提出 **Word Alignment Preference (WAP)**，利用词对齐覆盖率分数作为偏好信号，结合 DPO 优化 LLM 基机器翻译模型，以缓解长期困扰 MT 的幻觉（hallucination）与漏译（omission）问题。

---

## 研究问题与动机

- **LLM 引入 MT 后幻觉/漏译更加突出**： Decoder-only LLM 在预训练阶段大量阅读原始语料，天生容易产生幻觉；在翻译任务中进一步表现为过度翻译（over-translation）与欠翻译（under-translation）。
- **现有评估指标不足以衡量幻觉/漏译**：BLEU 与 COMET 得分提升不一定意味着幻觉/漏译减少，还受误译、流利度等因素干扰；且幻觉/漏译样本稀疏但一旦发生时后果严重。
- **词对齐与覆盖度是简单可行的信号**： preliminary 实验发现词对齐覆盖率分数（coverage score）与人工标注的幻觉/漏译程度呈强相关（Pearson 0.5969 / 0.5686），说明词对齐可作为偏好优化的有效指导信号。
- **偏好数据收集成本远低于指令数据**：相比人工标注 RLHF 或 instruction-tuning 数据，通过多个 MT 工具生成候选翻译并自动选取偏好的方式成本更低、可扩展性更好。

---

## 核心贡献（创新点）

1. **首次将词对齐覆盖率分数系统性地用于 LLM 基 MT 的偏好优化**：与以往仅关注整体翻译质量的偏好方法（如 ALMA-R）本质不同，本文直接针对幻觉/漏译这一细粒度问题设计信号。
2. **提出全自动词对齐偏好数据构造流水线（WAP）**：包括多工具翻译收集→词对齐覆盖率评分→偏好对选择→过滤去噪→DPO 优化五步，全程无需人工标注。
3. **设计了"难例选取 + GPT-4 覆盖率打分"的幻觉/漏译评估方案**：弥补 HalOmi 等既有基准只覆盖有限语言方向、且缺乏自动化评分的不足；并通过 GPT-4 在 HalOmi 上的实验验证其评估有效性。
4. **发现并揭示"人标注翻译也会存在漏译/幻觉"的现象**：构建的偏好数据中大量 human 翻译被选为 rejected，说明即便是人类参译也非完美，为后续 MT 数据质量控制提供了实证依据。

## 方法详解

### 3.1 多工具翻译候选收集
给定源句 $x$，使用 $K$ 个翻译工具生成候选集合 $Y = \{y^1, ..., y^K\}$，其中 $y^k = \pi^k(x)$。本文选取 DeepL、ChatGPT（gpt-3.5-turbo-0613）及人工翻译，冰岛语（is→en）因 DeepL 不支持改用 Google Translate。

### 3.2 词对齐覆盖率评分与偏好对选择
使用 WSPAlign 预测双向词对齐，过滤低置信对齐后，计算被至少一个目标词对齐覆盖的源词比例作为覆盖率分数 $\mathrm{C}(x, y^k) \in [0, 100]$。偏好对定义为：
$$
y^w = \arg\max_{y^k \in Y} \mathrm{C}(x, y^k), \quad y^l = \arg\min_{y^k \in Y} \mathrm{C}(x, y^k)
$$
三元组 $(x, y^w, y^l)$ 构成偏好训练样本。

### 3.3 三层过滤策略
为降低噪声：
- **覆盖率分差阈值**：$\mathrm{C}(x, y^w) - \mathrm{C}(x, y^l) < 5.0$ 的样本剔除；
- **语义相似度阈值**：用 LaBSE 计算的余弦相似度 $> 0.9$ 的样本剔除；
- **BLEU 反向检测**：chosen 翻译 BLEU $> 20.0$ 时剔除（防止模型直接抄袭源文获高分）。

### 3.4 DPO 优化
以 ALMA-13B 为 $\pi$ 与 $\pi_{ref}$，损失函数为：
$$
\mathcal{L} = -\log \sigma\!\left(\beta \log \frac{\pi(y^w|x)}{\pi_{ref}(y^w|x)} - \beta \log \frac{\pi(y^l|x)}{\pi_{ref}(y^l|x)}\right)
$$
超参：$\beta=0.1$，LoRA $r=16$，lr=$5\text{e}{-6}$，batch=64，4×A100 80G，训练 1 epoch，seed=42。

### 5.2 评估设计
- **难例选取**：按 Baseline COMET 最低选 N 个样本作为 hard instances（N=100/200/500），其余为 easy；
- **GPT-4 覆盖率评估**：用 gpt-4-0613 输出 0–100 分直接估计幻觉/漏译程度；
- **HalOmi 验证**：在 de→en/zh→en/ru→en 上计算 GPT-4 评分与人工标注的 Pearson 相关系数（幻觉 0.5969，漏译 0.5686），证明评估有效性。

## 实验与结果

### 数据集
- 训练偏好数据：20,074 triplets（训练）+ 2,226 triplets（开发），来自 WMT'17–'20 平行语料 + Flores-200；
- 测试集：WMT22（is→en 用 WMT21），共 17,372 句，覆盖 cs→en/de→en/is→en/zh→en/ru→en 五个方向及反向 5 个方向，共 10 组翻译方向。

### 基线
- ALMA-13B（相同训练数据起点）；
- FT_prefer / FT_reject（消融变体）。

### 关键结果

| 场景 | 指标 | 提升幅度 |
|------|------|----------|
| N=100 hard 实例（全部方向平均）| GPT-4 覆盖率 | **+4.96** |
| N=200 hard 实例 | GPT-4 覆盖率 | **+2.63** |
| N=500 hard 实例 | GPT-4 覆盖率 | **+1.24** |
| zh→en N=100 人工评估 | "无漏译"比例 | 56.00% → **80.00%** (+24%) |
| zh→en N=100 人工评估 | "全漏译"比例 | 4.33% → **0%** |
| zh→en N=100 人工评估 | "无幻觉"比例 | 64.00% → **75.66%** |
| 整体 BLEU | 部分方向 +1~3 | 平均略升 |
| 整体 COMET | 部分方向下降 | 差异不显著（p>0.05, margin<0.25）|

**最强结果**：GPT-4 覆盖率在 N=100 hard 场景下平均提升 **+4.96** 分；漏译问题改善尤为显著（全漏译降至 0%，无漏译提升 24%）。

## 相关工作脉络

1. **ALMA (Xu et al., 2024a)**：本文基线模型，从 Llama 两阶段训练；本文在其相同起点上做偏好优化，定位更聚焦幻觉/漏译。
2. **ALMA-R (Xu et al., 2024b)**：同期对比方法，使用无参考 MT 指标 + 人工标注做对比偏好优化；本文偏好数据完全自动构建，无需人工。
3. **DPO (Rafailov et al., 2024)**：直接偏好优化基础算法；本文首次将其引入 LLM 基 MT 的幻觉/漏译缓解场景。
4. **WSPAlign (Wu et al., 2023a)**：词对齐预训练模型，本文用作覆盖率分数预测器；其在多语言对齐任务上表现优于统计方法。
5. **HalOmi (Dale et al., 2023b)**：幻觉/漏译人工标注基准；本文用于验证 GPT-4 评估有效性，而非直接用于模型训练。
6. **Yang et al. (2019)**：早期利用词对齐减少漏译的工作；本文延续该思想，但扩展至 LLM 基 MT 并引入偏好学习范式。
7. **Tu et al. (2016)**：神经 MT 中建模覆盖度的开山之作；本文从信号层面（coverage score）而非模型架构层面利用覆盖信息。

## 局限性与未来方向

- **词对齐模型不完美的固有噪声**：即使经过三层过滤，对齐错误仍难以完全消除；低资源语言（如冰岛语）表现更差。
- **英语中心实验设置**：所有数据为英语-centric 对，无法反映非英语方向（如 cs→uk/zh→ja）中更严重的幻觉/漏译问题。
- **总体 MT 性能提升有限**：BLEU 略升、COMET 部分方向下降，整体效果"mixed"，说明覆盖度优化未必等价于翻译质量全面提升。
- **GPT-4 API 评估成本高昂**：依赖商用 LLM 作为评估器难以规模化复现，需探索低成本/无成本替代方案。
- **未处理过度翻译**：当前信号侧重"覆盖率"（防漏译），对幻觉中"过度生成"信息的惩罚机制较弱。

---

## 研究启发与可借鉴点

1. **"覆盖度信号→偏好优化"的范式可迁移**：任何具有显式对齐/覆盖度信号的任务（如文档级翻译、句子拼接）均可借鉴此流水线构造偏好数据。
2. **难例选取策略值得复用于其他 MT 优化工作**：按 Baseline COMET 最低 N 个样本划 hard/easy 子集，是评估特定改进在"困难样本"上效果的通用设计。
3. **GPT-4 覆盖率打分可作为幻觉/漏译的快速代理指标**：在 HalOmi 上验证有效（Pearson≈0.57–0.60），后续工作可直接采用该方案，避免昂贵人工标注。
4. **三层过滤策略（分差 + 语义相似度 + BLEU 反检）可推广**：对于任意自动构造偏好数据的场景，这三层去噪手段均可大幅降低噪声比例。
5. **人标注数据也非完美的发现**：提示团队在后续研究中应对高质量并行语料保持审慎，建立更严格的数据质量筛选流程。

## 关键术语表

- **Hallucination（幻觉）**：MT 中生成源文本未包含的信息，包括过度翻译与重复生成。
- **Omission（漏译）**：MT 中遗漏源文本已有信息的现象，包括部分信息或整句缺失。
- **Coverage Score（覆盖率分数）**：词对齐后，被至少一个目标词对齐覆盖的源词比例，范围 0–100，越高表示翻译越完整。
- **WSPAlign**：大规模弱监督预训练词对齐模型，本文用作覆盖率评分器。
- **DPO (Direct Preference Optimization)**：无需额外 reward model 的直接偏好优化方法，通过对比 chosen/rejected 对优化 $\pi$。
- **ALMA**：基于 Llama 的两阶段 LLM 基机器翻译模型，本文实验基线与起点。
- **HalOmi**：人工标注的多语言幻觉/漏译检测基准，涵盖 18 个语言方向。
- **Hard Instances（难例）**：按 Baseline COMET 最低选取的样本子集，更可能包含幻觉/漏译问题。
