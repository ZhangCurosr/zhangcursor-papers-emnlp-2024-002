# 论文速读：Rethinking-Token-Reduction-for-State-Space-Models

## 一句话总结
本文针对将现有 Transformer 的 token 缩减技术直接迁移到状态空间模型（SSM，如 Mamba）时性能断崖式下跌的问题，提出了一种统一的训练后 token 缩减方法（UTRC），通过解耦 token 重要度分类与相似度匹配，融合细粒度剪枝与合并策略，在显著降低 FLOPS 与显存占用的同时有效维持了模型精度。

## 研究问题与动机
- **核心问题**：如何为 SSM 架构设计有效的后训练 token 缩减策略，以实现推理加速与内存压缩？
- **现有方法为何不足**：
  1. **剪枝策略失效**：基于启发式指标移除低重要度 token 会造成不可逆信息丢失，且该丢失会在 SSM 的序列递推公式中被逐级放大。
  2. **合并策略失效**：现有分块合并方法（如 ToMe/PuMer）忽略 token 内在重要度，可能将关键 token 意外并入普通 token，导致序列输出严重偏离。
  3. **架构差异未被建模**：SSM 依赖隐状态通道交互而非注意力矩阵，直接套用 Transformer 的相似度评估与连接逻辑无法适配。
  4. **跨分支索引错位**：隐藏状态与残差连接的 token 若不同步缩减，层内重连时会破坏张量对齐，大幅削弱压缩收益。

## 核心贡献（创新点）
1. **首次系统性诊断 token 缩减在 SSM 上的失效机理**，明确指出剪枝的“不可逆信息丢失放大”与合并的“重要度忽视”两大根本原因。
2. **提出面向 SSM 的统一训练后缩减框架 UTRC**，首次将重要度分类与相似度匹配结合，提供细粒度层内缩减策略。
3. **设计解耦的二分-匹配-混合缩减流水线**，通过余弦相似度定向连接跨集合 token，并以可调控比例协同剪枝与合并，平衡信息保真与冗余消除。
4. **构建跨分支对齐的层次化部署方案**，针对隐藏状态采用混合策略、残差连接仅采用合并，配合跳层应用协议，兼顾压缩比与计算开销。

## 方法详解
- **Token 重要度量重新设计**：提取 SSM 层输出隐状态 $\mathbf{y} \in \mathbb{R}^{B \times N \times D'}$，利用所有特征通道的截断正值和评估每个 token 的重要性：
  $\mathcal{S} = \frac{\sum_{d=1}^{D'} \max(0, [\mathbf{y}]_{::d})}{D'}$。
  实验表明 clipped 值优于 L1/L2 norm 或无截断版本，能更精准反映 SSM 高维通道空间中的上下文贡献。
- **解耦分类与相似度匹配**：将 $N$ 个 token 按 $\mathcal{S}$ 降序排列，平分至低重要度集合 $M_A$ 与高重要度集合 $M_B$。对每个 $a_i \in M_A$，计算其与 $M_B$ 中所有 token 的余弦相似度，选定最相似目标 $f_i = \arg\max_{b_j \in M_B} \text{sim}(a_i, b_j)$，记录得分 $g_i$。
- **保留 Top-p% 连接并执行统一缩减（UTR）**：按 $g_i$ 排序保留前 $p\%$ 连接对。对保留对采用混合策略：剪枝 $(p \times q)\%$ 个 token（仅删除 $M_A$ 端），合并剩余 $[p \times (1-q)]\%$ 个 token（将 $a_i$ 与 $f_i$ 特征均值化后保留 $f_i$）。消融显示 $q=0.5$ 效果最佳。
- **跨分支差异化设计**：隐藏状态分支使用混合策略，残差连接分支仅使用合并。该设计确保两路输出的 token 集合严格一一对应，避免层末残差相加时的索引错位，最大化整体压缩比。
- **层次化应用协议**：相邻层 token 重要度高度相似，连续缩减开销大且收益递减。因此从第 10 层起每隔 5 层应用一次固定压缩比。例如 Mamba-2-2.7B 作用于层索引 [12, 17, 22, 27, 32, 37, 42]。

## 实验与结果
- **数据集与评估**：六个零样本常识推理 benchmark（LAMBADA, HellaSwag, PIQA, Arc-e, Arc-C, WinoGrade）；主要指标为 LAMBADA PPL 与六题平均准确率；FLOPS 缩减比例设为 10%、20%、30%。
- **对比模型**：EViT（剪枝）、PuMer（合并）、LTMP（ViT 阈值剪枝/合并）。
- **主要结果**：
  - **Mamba-2 系列**：相比最优基线，平均准确率提升 **5.7% ~ 13.1%**。例如 Mamba-2-1.3B 在 20% FLOPS 缩减下较 EViT 提升 10%（54.6% vs 44.2%）；Mamba-2-2.7B 在 30% 缩减下提升 13.1%。
  - **Mamba 系列**：平均准确率提升 **6.5% ~ 15.1%**。Mamba-1.4B 在 20% 缩减下达到 53.4%，显著优于 EViT 的 41.1%。
  - **PPL 控制**：基线方法在 20%~30% 缩减下 PPL 飙升至数千至数万，而本文方法始终维持在个位至两位数（如 Mamba-2-2.7B 30% 下为 42.61）。
  - **显存与吞吐**：Mamba-2-2.7B 在 10%/20%/30% FLOPS 缩减下峰值显存分别降低 11.4%/20.3%/30.6%；生成吞吐量最高提升 **1.37x**（30% 缩减）。
- **消融结论**：clipped 重要度量、$q=0.5$ 混合策略、残差仅合并、跳跃层应用（[12,17,...,42]）均为最优配置组合。
